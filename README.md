# med-simplifier

Агент для упрощения медицинских текстов (ru + en)

---

## Первичные метрики

### `base_metrics.py`

| Метрика | Описание |
|---------|----------|
| ASL | Средняя длина предложения в словах |
| FKGL | Индекс читаемости Флеша-Кинкейда. ru: `0.5×ASL + 8.4×ASW − 15.59`, en: `0.39×ASL + 11.8×ASW − 15.59` |
| SMOG | ru: `1.1×√(64.6/n_предл × n_длинных) + 0.05`, en: `1.043×√(n_длинных×30/n_предл) + 3.13` |
| Доля длинных слов | Доля слов ≥4 слогов (ru) или ≥3 слогов (en) |
| TTR | Уникальные леммы / все леммы |
| Yule's K | `10⁴ × (Σ Vx×x² − N) / N²`. Чем выше — тем беднее словарь |

### `metrics.py` — требует spaCy doc

| Метрика | Описание |
|---------|----------|
| Редких слов | Доля слов с Zipf-частотой < 3 по wordfreq |
| Подчинение | Число клауз acl / advcl / ccomp / mark на предложение (UD-разбор) |
| Пассив/причастие | Доля токенов с dep=nsubj:pass или aux:pass, либо VerbForm=Part (en: ещё Ger) |
| NVR | Существительные / глаголы (noun-verb ratio) |
| NOUN+NOUN | Доля пар соседних существительных — маркер номинального стиля |
| Медтермины | Доля слов из встроенного словаря + аббревиатуры по regex |
| Числа/единицы | Доля числовых выражений с единицами измерения по regex |
| Генит. цепочки | Только ru. Доля пар NOUN→NOUN, где зависимое в родительном падеже |

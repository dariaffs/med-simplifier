# med-simplifier

Агент для упрощения медицинских текстов (ru + en)

---

## Первичные метрики. Считаются и для исходного текста, и для упрощенного.

### Базовые метрики `base_metrics.py`

| Метрика | Описание | Формула для русского | Формула для английского |
|---------|----------|----------------------|------------------------|
| ASL | Средняя длина предложения (в словах) | `n_слов / n_предл` | `n_слов / n_предл` |
| FKGL | Индекс читаемости Флеша-Кинкейда и его адаптированный вариант для русского | `0.5×ASL + 8.4×ASW − 15.59` | `0.39×ASL + 11.8×ASW − 15.59` |
| Flesch Reading Ease / Индекс Оборневой | Индекс удобочитаемости, у которого меньшее значение соответствует более сложному тексту | `206.835 − 1.52×ASL − 65.14×ASW` | `206.835 − 1.015×ASL − 84.6×ASW` |
| SMOG | Уровень сложности (по многосложным словам) | `1.1×√(64.6/n_предл × n_длинных) + 0.05` | `1.043×√(n_длинных×30/n_предл) + 3.13` |
| Доля длинных слов | Доля слов с колическтвом слогов выше порога TODO убедиться с порогами| `n_слов(≥4 слога) / n_слов` | `n_слов(≥3 слога) / n_слов` | 
| TTR | Лексическое разнообразие (отношение числа различных лемм к числу всех лемм) | `n_уникальных_лемм / n_всех_лемм` | `n_уникальных_лемм / n_всех_лемм` |
| Yule's K | Лексическое разнообразие (доли гапаксов (лемм, встретившихся один раз или два раза)) | `10⁴ × (Σ Vx×x² − N) / N²` | `10⁴ × (Σ Vx×x² − N) / N²` |

### Метрики, для подсчета которых необходим spacy `metrics.py`

| Метрика | Описание | Формула для русского | Формула для английского |
|---------|----------|----------------------|------------------------|
| Доля редких слов | Доля слов, частотность которых по шкале Ципфа попадает в низкий диапазон | `n_слов(Zipf < 3) / n_слов` | `n_слов(Zipf < 3) / n_слов` |
| Синтаксическая сложность по подчинению и сочинению | Повышает оценку сложности, если предложение сложноподчинённое или сложносочинённое, и учитывает наличие союзов («и», «что», «или») | `n_клауз(acl, advcl, ccomp, mark) / n_предл` | `n_клауз(acl, advcl, ccomp, mark) / n_предл` |
| Доля пассивных конструкций и причастий | Доли пассивных конструкций со вспомогательным глаголом (Aux:pass_pr), пассивных подлежащих (Nsubj:pass_pr), полных и кратких страдательных причастий (Pssv_prtf_pr, Pssv_prts_pr) и деепричастий (Grnd_pr) | `n_токенов(nsubj:pass, aux:pass, VerbForm=Part) / n_слов` | `n_токенов(nsubj:pass, aux:pass, VerbForm=Part, VerbForm=Ger) / n_слов` |
| NVR | Соотношение существительных и глаголов | `(n_NOUN + n_PROPN) / (n_VERB + n_AUX)` | `(n_NOUN + n_PROPN) / (n_VERB + n_AUX)` |
| Биграммы NOUN + NOUN | Доля цепочек существительных (NOUN + NOUN) | `n_пар(NOUN+NOUN) / n_слов` | `n_пар(NOUN+NOUN) / n_слов` |

ПРЕДВАРИТЕЛЬНЫЕ

| Метрика | Описание | Формула для русского | Формула для английского |
|---------|----------|----------------------|------------------------|
| Медтермины | Плотность медицинской лексики | (n_слов(словарь) + n_аббревиатур) / n_слов | то же |
| Числа/единицы | Плотность числовых выражений | n_совпадений(regex) / n_слов | то же |
| Генит. цепочки | Цепочки существительных в родительном падеже | n_пар(NOUN→NOUN, Case=Gen) / n_слов | — |
